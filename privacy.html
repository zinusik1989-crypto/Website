Политика конфиденциальности

Актуальная редакция с учётом мини-игры на сайте, баннера согласия на cookies и обработку персональных данных, а также хранения данных только в вашем браузере.

Настоящая Политика конфиденциальности (далее — «Политика») определяет порядок обработки и защиты персональных данных пользователей сайта «Зинаида | Фото мечты без камеры» (далее — «Сайт»), размещённого как статическая веб-страница (в том числе на GitHub Pages). Сайт не имеет регистрации пользователей и базы данных посетителей на сервере Оператора.

2. Какие данные могут обрабатываться

В зависимости от того, как вы пользуетесь Сайтом, могут обрабатываться:

  • Контактные данные, которые вы добровольно передаёте при обращении (имя, телефон, ник в мессенджере, email — если укажете).
  • Содержание обращения — текст запроса, пожелания по съёмке, ссылки на референсы.
  • Изображение (фото лица) — только при загрузке в мини-игре «Покажи лицо Северу» и при согласии на обработку ПДн (п. 5–6). Файл обрабатывается локально в браузере; на сервер Сайта по умолчанию не отправляется.
  • Данные прохождения мини-игры (при «Принять»): ответы в сценарии, стиль образа, отметка о загрузке фото — текстом в localStorage. Сам файл фото в запись не включается.
  • Настройки интерфейса в браузере (тема, мобильная вёрстка, запись о согласии).

Сайт не использует сквозную веб-аналитику (Google Analytics, Яндекс.Метрика и т.п.) и рекламные пиксели.

3. Цели обработки

  • Ответ на обращение, консультация и согласование условий нейрофотосессии / AI-визуала.
  • Исполнение договорённостей по услугам после вашего запроса.
  • Работа интерактивной мини-игры на Сайте (подбор образа, демонстрация сценария).
  • Сохранение удобных настроек отображения и учёт вашего выбора в баннере согласия.

4. Правовые основания

  • Согласие субъекта ПДн — «Принять» в баннере, загрузка фото в мини-игре, обращение через контакты.
  • Исполнение договора / преддоговорные действия — при заказе услуг по вашей инициативе.
  • Законный интерес Оператора — минимально необходимые технические настройки при выборе «Только необходимые».

5. Баннер согласия (cookies и персональные данные)

При первом посещении внизу экрана показывается уведомление. Варианты:

  • «Принять» — согласие на обработку ПДн (фото в мини-игре, обращение через контакты) и на все записи в браузере из п. 6. Кнопка активна только при отмеченном чекбоксе о согласии на обработку ПДн.
  • «Только необходимые» — только тема и мобильный режим; загрузка фото и сохранение результатов игры недоступны.

Выбор сохраняется в localStorage (zin_consent_v1). Отозвать согласие: очистить данные Сайта в браузере или написать Оператору по контактам из раздела «Контакты».

6. Cookies, localStorage и срок хранения в браузере

Сайт преимущественно использует localStorage. Записи на устройстве:

  • zin_consent_v1 — выбор в баннере согласия;
  • polarTheme — тема оформления (необходимая настройка);
  • forceMobile — режим «Мобильная версия» (необходимая настройка);
  • zin_game_results_local_v1, zin_game_results_import_v1 — результаты мини-игры (только при «Принять», без файла фото);
  • zin_site_cms_v1 — правки текстов в admin.html, только в браузере редактора; к посетителям не относится.

Данные хранятся до удаления вами в настройках браузера. Рекламное профилирование не применяется. Передача содержимого localStorage на сервер Оператора по умолчанию не производится.

7. Мини-игра «Покажи лицо Северу»

На главной — секция «Север выбирает твою судьбу»:

  • фото показывается только в вашем браузере (временный адрес в памяти);
  • после закрытия вкладки превью не сохраняется на Сайте;
  • при «Принять» может сохраняться описание результата (стиль, ответы) — п. 6;
  • просмотр результатов — только в admin.html на том же устройстве и в том же браузере (PIN), без выгрузки на облако Сайта.

Генерация AI-изображения через внешние API на публичном Сайте не подключена. При появлении такой функции Политика будет дополнена.

8. Передача третьим лицам и внешние ресурсы

Персональные данные не продаются. Возможна передача или обработка:

  • по вашей инициативе — Telegram, WhatsApp, VK, email и др. из раздела «Контакты»;
  • хостинг и доставка контента — GitHub Pages, Google Fonts, CDN jsDelivr (технические данные соединения: IP, браузер);
  • по требованию закона — уполномоченным органам РФ.

9. Сроки хранения

  • localStorage — до удаления вами или отзыва согласия;
  • переписка по услугам — в срок исполнения договорённостей или до отзыва согласия;
  • превью фото в мини-игре — только на время сессии в браузере.

10. Безопасность

Оператор применяет разумные меры: PIN для служебной панели, отсутствие централизованного хранения фото посетителей на сервере Сайта, доступ по HTTPS. Безопасность мессенджеров зависит от выбранного канала.

11. Права пользователя

Вы вправе:

  • получить информацию об обработке ваших персональных данных;
  • потребовать уточнения, блокирования или удаления данных;
  • отозвать согласие — через браузер и/или обращение к Оператору;
  • обжаловать действия Оператора в уполномоченный орган по защите прав субъектов ПДн.

12. Изменения Политики

Политика обновляется при изменении функционала Сайта. Актуальная версия — на этой странице. При существенных изменениях баннер согласия может быть показан повторно.

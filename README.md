# Сайт-визитка «Зинаида | Фото мечты без камеры»

Одностраничный лендинг в стиле **luxury editorial / полярная ночь** (тёмный фон с северным сиянием, цветные акценты cyan/mint/violet) с плавными анимациями появления, адаптивной сеткой, лайтбоксом-альбомом и простой локальной CMS.

## Возможности

- **Hero** с фото на фоне «северного сияния», заголовком и кнопками-CTA.
- **Услуги, прайс-лист, отзывы, процесс, контакты** — секции с reveal-анимациями.
- **Портфолио-альбомы**: 4 карточки (женский, мужской, дети, семья) → лайтбокс с миниатюрами, навигацией стрелками/свайпом и подгрузкой соседних кадров.
- **Локальная CMS** (`admin.html` + `cms.js`): редактирование всех текстов и ссылок в браузере, данные хранятся в `localStorage`. Защита PIN-кодом (по умолчанию `2026`). Поддерживает экспорт/импорт JSON.
- **Переключатель «Мобильная версия»** — кнопка слева снизу (`📱 / 🖥`), форсирует мобильную раскладку на любом экране. Состояние сохраняется в `localStorage`.
- **Адаптивность**: 3 контрольные точки (980px / 720px / 420px) + мобильное off-canvas меню.
- **A11y и SEO**: семантическая разметка, `aria-label`, skip-link, canonical, Open Graph и Twitter Card.
- **Политика конфиденциальности** (`privacy.html`) — статичная страница с шапкой/футером, синхронизированными через CMS.

## GitHub и GitHub Pages

### 1. Установите Git

Если команда `git` в терминале не находится, установите [Git for Windows](https://git-scm.com/download/win) и перезапустите терминал.

### 2. Создайте репозиторий на GitHub

На [github.com/new](https://github.com/new) создайте пустой репозиторий (без README, без `.gitignore` от GitHub — они уже есть в проекте).

### 3. Первый push из папки проекта

В PowerShell или «Git Bash» (подставьте свой URL репозитория):

```bash
cd "путь/к/Проект Курсор"
git init
git branch -M main
git add .
git commit -m "Initial commit: landing + GitHub Pages"
git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПО.git
git push -u origin main
```

Дальше достаточно `git add`, `git commit`, `git push` — сайт обновится после успешного workflow.

### 4. Включите GitHub Pages

В репозитории: **Settings → Pages → Build and deployment**.

- **Source:** выберите **GitHub Actions** (не «Deploy from a branch»).

После первого успешного запуска workflow адрес будет вида `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПО/` — его же можно указать в **Settings → Pages** в поле отображаемого URL.

Ручной перезапуск деплоя: вкладка **Actions → GitHub Pages → Run workflow**.

### Примечания

- Ветка для деплоя задана как **`main`**. Если используете только `master`, в файле `.github/workflows/github-pages.yml` замените `branches: [main]` на `[master]` или переименуйте ветку: `git branch -M main`.
- Секреты в репозитории для этого workflow не нужны: используется встроенный `GITHUB_TOKEN` и разрешения `pages: write` + `id-token: write`.
- В **опубликованную** папку попадают только HTML/CSS/JS, `cms.js`, `.nojekyll` и изображения в корне (`*.png`, `*.jpg` и т.д.) — не весь репозиторий, чтобы на Pages не оказывались служебные каталоги вроде `.git`.

## Колесо северной судьбы

Секция `#arctic-wheel`: выбор пола (женский / мужской) → квиз (4 вопроса) → колесо (6 стилей) → AI-скан → карточка результата на русском. Названия на колесе, описания, одежда и статы подстраиваются под выбранный пол.

Файлы: `arctic-wheel.js`, `arctic-wheel.css` (префикс `.arctic-wheel-section`).

## Север выбирает твою судьбу

Секция `#arctic-story-game`: cinematic story game — портал → загрузка фото (только в браузере) → AI-скан → 3 героя с выборами → ритуал → результат с prompt и кнопками.

Файлы: `arctic-story-game.js`, `arctic-story-game.css` (префикс `.arctic-story-game`).

## Запуск

- **Самый простой способ**: откройте `index.html` в браузере двойным кликом.
- **Через локальный сервер** (рекомендуется, чтобы корректно работали относительные пути и шрифты):

```bash
npx serve .
```

После запуска откройте адрес, который покажет команда.

## Админка

1. Откройте `admin.html` в браузере → введите PIN (по умолчанию `2026`, задаётся в `cms.js` → `SiteCMS.ADMIN_PIN`).
2. Меняйте тексты, цены, ссылки. Жмите **«Сохранить»** — изменения сохраняются в `localStorage` этого браузера.
3. Откройте `index.html` — `cms.js` подменит все тексты с атрибутом `data-cms`.

**Важно:** CMS работает только локально в вашем браузере. Чтобы правки увидели посетители боевого сайта, нужно либо:
- скопировать значения вручную в HTML, либо
- экспортировать JSON и подложить его как данные на бэкенд / захардкодить как объект defaults в `cms.js`.

PIN-код виден всем в исходниках страницы — это **не серверная защита**, а лишь барьер от случайных правок. Перед публикацией смените PIN или вовсе удалите `admin.html` из продакшена.

## Оптимизация изображений

Сайт отдаёт **WebP** (лёгкие копии рядом с PNG/JPG). Скрипты в `scripts/`:

```powershell
# WebP для arctic-*.png + сжатие JPG в папке Фото/
powershell -ExecutionPolicy Bypass -File scripts/optimize-images.ps1
powershell -ExecutionPolicy Bypass -File scripts/compress-jpegs.ps1
```

После добавления новых фото в `Фото/` снова запустите оба скрипта. В браузере подставляется `.webp` через `img-opt.js` и `cms.js` (`displaySrc`).

| Было (пример) | Стало |
|---|---|
| Hero `arctic-aurora.png` ~2,1 МБ | `arctic-aurora.webp` ~120 КБ |
| Альбом JPG ~26 МБ | JPG ~7 МБ + WebP для лайтбокса |
| Favicon | `arctic-icon-192.webp` ~11 КБ |

PNG-оригиналы в репозитории можно оставить как резерв; на странице используются WebP.

## Что менять под себя

- **Фото портрета и превью карточек** — `src`/`data-cms-src` в `index.html`, ключи `portrait_img`, `work_*_img` в `cms.js` (формат `.webp`).
- **Файлы лайтбокса** — списки `ARCTIC_FILES`, `WOMEN_FILES` и `ALBUM_FILES` в `script.js` (в лайтбоксе подгружается WebP).
- **Контакты** — блок `#contacts` в `index.html` или ключи `contact_*` / `cta_*_href` в админке.
- **Тексты / услуги / тарифы** — `index.html` или соответствующие разделы в админке.
- **Цвета / типографика / эффекты** — `styles.css` (CSS-переменные в `:root` и `--polar-*-rgb`).
